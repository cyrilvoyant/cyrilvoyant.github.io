ARTU: a second-order solar reference, worked example

Principle 3 · Complexity only if it paysThe approach

In the story: a demanding second-order reference, computed by hand.

Worked example. All input values below are fictitious teaching values, not observations or results from the cited paper.

Result: the published lookup table gives K = -0.03 and α = 0.81 for the illustrative correlations below. The resulting forecast is 496.628 W/m².

Begin with the right variable

Here κ(t) = GHI(t)/CS(t) is a dimensionless clear-sky ratio. It is distinct from the additive clear-sky gap used in some course examples. Near night and twilight, a ratio needs the safeguards specified by the algorithm.

The theory

ARTU is a second-order reference on the clear-sky ratio \(\kappa(t)=\mathrm{GHI}(t)/\mathrm{CS}(t)\). Its two coefficients are not fitted freely: they are read in a published table from two correlations estimated on training data.

\(\rho_1,\ \rho_2\)
autocorrelations of \(\kappa\) at lags \(h\) and \(2h\) (training data only)
\(K,\ \alpha\)
coefficients read in the lookup table at \((\rho_1,\rho_2)\)
\(\bar\kappa\)
historical mean of \(\kappa\)
$$S=\alpha+K,$$ $$P=\alpha K,$$ $$\hat\kappa(t+h)=S\,\kappa(t)-P\,\kappa(t-h)+(1+P-S)\,\bar\kappa,$$ $$\widehat{\mathrm{GHI}}(t+h)=\hat\kappa(t+h)\,\mathrm{CS}(t+h).$$

The weights \(S\), \(-P\) and \(1+P-S\) sum to 1, so the forecast returns to \(\bar\kappa\) when the recent values equal it. Night and twilight need the safeguards of Algorithm 5 of the source; a cap \(\beta\) limits \(\hat\kappa\).

Read the coefficients, then calculate

  1. Choose training-only correlations ρ₁ = 0.80 at lag h and ρ₂ = 0.65 at lag 2h. These are fictitious inputs.
  2. Choose the source table R0.05.mat (R = 0.05). At this exact grid node, row 37 and column 34 in MATLAB’s one-based indexing, res_K = −0.03 and res_a = 0.81. No interpolation is needed here.
  3. Form S = α + K = 0.78 and P = αK = −0.0243.
  4. Take κ(t) = 0.60, κ(t−h) = 0.65 and historical mean κ̄ = 0.70.
  5. Compute κ̂ = Sκ(t) − Pκ(t−h) + (1+P−S)κ̄ = 0.468 + 0.015795 + 0.136990 = 0.620785.
  6. With future clear sky CS(t+h) = 800 W/m², multiply κ̂ by 800 to obtain 496.628 W/m². A cap β = 1.2 is inactive in this example.

Try it in your browser

Move ρ(h) and ρ(2h), or click on the map, choose the measurement quality R, and read α, K and the weights of the forecast, from the tables of the article. Let R grow to see how a noisier measurement changes the coefficients.

Run it

Reads the grid node used in this example (executed with MATLAB R2025b on 22 October 2026).

% from a clone of github.com/cyrilvoyant/ARTU: unzip K_alpha.zip, then
load('R0.05.mat');
fprintf('ARTU table: K = %.2f, alpha = %.2f\n', res_K(37,34), res_a(37,34));

Output:

ARTU table: K = -0.03, alpha = 0.81

Compare meaningful references

For this same clear-sky value, ratio persistence gives 0.60 × 800 = 480 W/m²; climatology gives 0.70 × 800 = 560 W/m². Without a future observation, none can be declared more accurate.

What this study contributes

The benchmark study introduces ARTU as a second-order reference alongside simpler baselines. ARTU’s table-based parameters must not be confused with fitting an arbitrary two-lag AR model by least squares.

Reproduce and check the limits

Download K_alpha.zip, load R0.05.mat and inspect res_K(37,34) and res_a(37,34). The source PDF, Algorithm 5, specifies the update and preprocessing. The current K_alpha.m function takes an argument named Q but tests R internally; check that variable mismatch before running the wrapper. This example reads the table directly and does not modify the repository. Do not silently extrapolate beyond the table or use future observations for correlations.

Source repository, tables and Algorithm 5

Key point: ARTU uses two correlations and a table of coefficients. This example follows the published table; it is not a freely fitted AR(2).
