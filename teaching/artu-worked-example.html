ARTU: a second-order solar reference, worked example

See where ARTU’s coefficients come from

ARTU forecasts the ratio to trend by combining three things: the latest value, the previous value and the historical mean. Their weights come from a published table selected using signal memory. Change the series to see the forecast and its errors respond.

The signal κ (kappa) is the ratio to trend: measured irradiance divided by clear-sky irradiance, dimensionless. Here we simulate this ratio to isolate memory and cycle effects.

1. Build the signal

0: no memory; 0.95: highly persistent.

What signal is simulated?

κ is a dimensionless simulated ratio to trend: 0.7 + amplitude × sin(2πt/24) + 0.08z(t). Noise follows z(t) = φz(t−1) + √(1−φ²)η(t), with standard normal η. The series is bounded to [0.05, 1.15], with any bounded values counted. These 1,464 steps are abstract daytime samples: neither observed weather nor a day/night calendar.

The data are simulated; coefficient tables come from the published code. This experiment does not reproduce the paper’s validation.

2. From measured memory to forecast weights

Comparison reference: persistence copies the last available irradiance at the chosen horizon. Clear sky is constant at 800 W/m² here, so persisting irradiance is equivalent to persisting the ratio to trend.

NICE² · against persistenceNICE²—ARTU RMSE / persistence RMSE. Below 1: lower error; 1: equal error; > 1: worse.
Relative error · nRMSEnRMSE—RMSE / mean of test observations. RMSE: square root of mean squared errors.
Absolute error · MAEMAE—Mean absolute error in W/m²; a 10 W/m² error counts equally in either direction.

ⓘ Understand NICE and its reference

NICE² = model RMSE / persistence RMSE, using the same targets and horizon. 0: perfect forecast; between 0 and 1: lower error than persistence; 1: equal error; > 1: worse. If persistence error is zero, the ratio is undefined. Displaying > 1 retains the fact that the reference performs better.

Full NICE definition and sources

ⓘ Why can assumed noise have little effect on error?

The 1%, 5%, 10% choices concern measurement-noise variance divided by signal variance. They are not 1%, 5%, 10% relative irradiance errors; the standard-deviation ratios would be 10%, 22.4%, 31.6%. They change the coefficient table without injecting noise into the simulated data. Effects on error depend on correlations and horizon: no dramatic effect is fabricated.

How it is calculated

ρ(h) measures resemblance to the series h steps earlier; ρ(2h) does the same at 2h steps. Both correlations are dimensionless.

nRMSE = root mean squared error / mean of test observations, in %. MAE = mean absolute irradiance error, in W/m². Clear-sky irradiance is fixed at 800 W/m² at every step in this experiment: convert the ratio to trend to irradiance by multiplying by 800. All three references share the same targets and horizon.

In the story: a demanding second-order reference, computed by hand.

Worked example. All input values below are illustrative inputs for this fixed calculation, not observations or results from the cited paper.

Result: the published lookup table gives K = -0.03 and α = 0.81 for the illustrative correlations below. The resulting forecast is 496.628 W/m².

Begin with the right variable

Here κ(t) = GHI(t)/CS(t) is a dimensionless ratio to trend (the clear-sky index), with GHI the global horizontal irradiance and CS the clear-sky irradiance. It is distinct from the difference to trend used in some course examples. Near night and twilight, a ratio needs the safeguards specified by the algorithm.

The theory

ARTU is a second-order reference on the ratio to trend \(\kappa(t)=\mathrm{GHI}(t)/\mathrm{CS}(t)\). Its two coefficients are not fitted freely: they are read in a published table from two correlations estimated on training data.

\(\rho_1,\ \rho_2\)
autocorrelations of \(\kappa\) at lags \(h\) and \(2h\) (training data only)
\(K,\ \alpha\)
coefficients read in the lookup table at \((\rho_1,\rho_2)\)
\(\bar\kappa\)
historical mean of \(\kappa\)
$$S=\alpha+K,$$ $$P=\alpha K,$$ $$\hat\kappa(t+h)=S\,\kappa(t)-P\,\kappa(t-h)+(1+P-S)\,\bar\kappa,$$ $$\widehat{\mathrm{GHI}}(t+h)=\hat\kappa(t+h)\,\mathrm{CS}(t+h).$$

The weights \(S\), \(-P\) and \(1+P-S\) sum to 1, so the forecast returns to \(\bar\kappa\) when the recent values equal it. Night and twilight need the safeguards of Algorithm 5 of the source; a cap \(\beta\) limits \(\hat\kappa\).

Read the coefficients, then calculate

  1. Choose training-only correlations ρ₁ = 0.80 at lag h and ρ₂ = 0.65 at lag 2h. These values are for this numerical example only.
  2. Choose the source table R0.05.mat (R = 0.05). At this exact grid node, row 37 and column 34 in MATLAB’s one-based indexing, res_K = −0.03 and res_a = 0.81. No interpolation is needed here.
  3. Form S = α + K = 0.78 and P = αK = −0.0243.
  4. Take κ(t) = 0.60, κ(t−h) = 0.65 and historical mean κ̄ = 0.70.
  5. Compute κ̂ = Sκ(t) − Pκ(t−h) + (1+P−S)κ̄ = 0.468 + 0.015795 + 0.136990 = 0.620785.
  6. With future clear sky CS(t+h) = 800 W/m², multiply κ̂ by 800 to obtain 496.628 W/m². A cap β = 1.2 is inactive in this example.

Run it

Reads the grid node used in this example (executed with MATLAB R2025b on 22 October 2026).

% from a clone of github.com/cyrilvoyant/ARTU: unzip K_alpha.zip, then
load('R0.05.mat');
fprintf('ARTU table: K = %.2f, alpha = %.2f\n', res_K(37,34), res_a(37,34));

Output:

ARTU table: K = -0.03, alpha = 0.81

Compare meaningful references

For this same clear-sky value, persistence of the ratio to trend gives 0.60 × 800 = 480 W/m²; climatology gives 0.70 × 800 = 560 W/m². Without a future observation, none can be declared more accurate.

What this study contributes

The benchmark study introduces ARTU as a second-order reference alongside simpler baselines. ARTU’s table-based parameters must not be confused with fitting an arbitrary two-lag AR model by least squares.

Reproduce and check the limits

Download K_alpha.zip, load R0.05.mat and inspect res_K(37,34) and res_a(37,34). The source PDF, Algorithm 5, specifies the update and preprocessing. The current K_alpha.m function takes an argument named Q but tests R internally; check that variable mismatch before running the wrapper. This example reads the table directly and does not modify the repository. Do not silently extrapolate beyond the table or use future observations for correlations.
