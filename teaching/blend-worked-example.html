BLEND persistence: a step-by-step forecast

Worked example / Exemple chiffré. All input values below are fictitious teaching values, not observations or results from the cited paper.

Result: with today’s 12:00 irradiance 600 W/m², yesterday’s 13:00 value 400 W/m² and a weight λ = 0.6 fitted on five past days, BLEND predicts 480 W/m² for 13:00.

The question / La question

Should the next forecast follow the latest measurement or the recurring daily pattern? BLEND mixes both, with one weight per hour of the day. That weight is a one-line least-squares fit on past days; it is the same weight as the full cyclostationary BLEND formula, written with cyclic means, deviations and correlations.

Calculate it, without using the future

  1. Set the forecast origin t to 12:00 today, horizon h to one hour and cycle T to 24 hours. The target is 13:00 today.
  2. For each past day, note r = I(12:00), c = I(13:00 the day before) and y = I(13:00), the value that was to be forecast.
  3. Fit the weight of the cyclic term: λ = Σ (c − r)(y − r) / Σ (c − r)² = 43,500 / 72,500 = 0.6. Keep λ between 0 and 1.
  4. Today, r = 600 and c = 400: Î(13:00) = λ c + (1 − λ) r = 0.6 × 400 + 0.4 × 600 = 480 W/m².

What the code shows

The weight per phase beats previous-cycle persistence at every horizon and smart persistence from three steps ahead, without a clear-sky model. The simplified weight (1 + ρ)/2 assumes the same mean at t and t + h; on a daily cycle it only helps one or two steps ahead.

What this study contributes

The published study develops a family of analytical forecasting operators for periodically correlated energy signals. The calculation illustrates its BLEND member; it does not reproduce the full benchmark.

Limits that matter

A convex combination stays between its two inputs; this alone says nothing about forecast accuracy. The weight needs enough past cycles, changes with phase and horizon, and must not be fitted on the test period. Version 1.1.0 of the MATLAB code fixes an indexing error of v1.0.0 that compared some forecasts with already known values.
