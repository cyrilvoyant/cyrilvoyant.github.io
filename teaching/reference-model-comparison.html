Persistence, AR and ELM: compare forecasts on public PV data

Principle 3 · Complexity only if it paysThe approach

In the story: simple references compared on public data before any complex model.

Protocol audit: interpret this as a minimal baseline exercise

This demonstration deliberately uses only six raw-power lags. Unlike the author’s reference implementation, it omits target-time cyclic features and astronomical night masking. It can consequently predict positive PV power after sunset, especially at three hours. These results must not be used to characterize the performance of PV_ELM_pred or the associated research.

The independent audit found no target-time shift or RMSE arithmetic error. It did find that this simplified protocol is inadequate as a showcase of the full forecasting methods. The existing numbers are retained transparently, rather than replaced by models selected after examining their test errors.

At one hour, the displayed ELM-30 RMSE is 1.568 kW versus 1.895 kW for raw persistence (17.3% reduction). At three hours it is 2.698 kW, including avoidable nocturnal errors. These are whole-test errors, not errors for the plotted week. Further comparison should reproduce the reference preprocessing and report daytime/all-hours metrics separately.

The theory

Reference forecasts

At origin \(t\) and horizon \(h\), with cycle length \(T\) (24 hourly steps for a day):

$$\hat y^{\,\mathrm{P}}_{t+h}=y_t\quad(\text{persistence}),$$ $$\hat y^{\,\mathrm{C}}_{t+h}=y_{t+h-T}\quad(\text{cyclic persistence: same phase, previous cycle}).$$

AR(6) and ELM on six lags

Input \(\mathbf x_t=[y_t,\dots,y_{t-5}]\), standardised on the training part only.

$$\text{AR(6): }\ \hat y_{t+h}=a_0+\mathbf a^{\top}\mathbf x_t,$$ $$\text{ELM: }\ \hat y_{t+h}=\tanh\!\left(W\mathbf x_t+\mathbf b\right)^{\top}\beta+\beta_0,$$

with \(W,\mathbf b\) Gaussian random and fixed, and \((a_0,\mathbf a)\) and \(\beta\) fitted by ridge regression whose penalty is chosen on the validation part. Stored coefficients: \(7\) for AR(6), \(6L+L+(L+1)\) for an ELM with \(L\) neurons (81 for \(L=10\), 241 for \(L=30\)).

$$\mathrm{RMSE}=\sqrt{\frac1N\sum_{t}\left(y_{t+h}-\hat y_{t+h}\right)^2}\quad\text{on the whole test period, day and night.}$$

Protocol: keep the future out

  1. Data: the public half-hour Palaiseau example in PV_ELM_pred/data.zip, with UTC timestamps and AC power in W.
  2. Chronological split: first 60% training, next 20% validation, last 20% test. Split dates and a source checksum are in the downloadable JSON.
  3. Six observations at or before forecast origin form the input. Standardization is estimated on training only. Each horizon is trained separately.
  4. AR is linear ridge regression with an intercept. ELM uses fixed Gaussian random input weights and tanh activation; only output weights are fitted. Ridge penalty is selected on validation from a fixed grid.
  5. Test targets never enter model fitting or penalty selection. Forecasts are clipped at zero. Night observations are retained; no filter uses the future observed production.

Size, variability and limits

AR stores 7 fitted coefficients. ELM-10 stores 81 coefficients (11 fitted); ELM-30 stores 241 (31 fitted), excluding scaling constants and runtime overhead. Three random ELM seeds are evaluated; the chart and table display seed 0. The downloadable report includes the three test errors. Do not select the best seed on test.

This is one site and one chronological split. Six lags and hidden sizes are fixed teaching choices. A daytime score, rolling evaluation, additional seasons and sites could change the conclusions. Persistence here means raw-power persistence; it is not smart persistence, BLEND or ARTU. Hardware energy and latency were not measured.

Reproduce and cite

Download observations, forecasts and protocol JSON · Download the calculation script (Python 3; install numpy, pandas and requests) · Public source dataset, original software and team credits.

ELM foundation: Guang-Bin Huang, Qin-Yu Zhu and Chee-Kheong Siew (2006), Extreme learning machine: Theory and applications. This page implements a small teaching model; it does not claim ELM’s invention or reproduce every PV_ELM_pred variant.

How to read it: compare methods on the same observations and the same horizon. The error shown covers the whole test, not only the week in the chart. A bigger model is not automatically better; this single calculation does not establish the general ranking of methods.
