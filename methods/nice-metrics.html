NICEᵏ metrics for solar forecast evaluation

Principle 5 · Trust is demonstratedThe approach

In the story: measure what a model adds. NICE divides a model's error by that of persistence, so 1 means no gain at all.

What does NICE add?

The study organizes deterministic forecast evaluation relative to explicit reference errors. The baseline, normalization and identical scoring sample must be stated before interpreting a score.

Cyril Voyant · Updated 2026-10-20

The NICEᵏ metrics (Normalized Informed Comparison of Errors), introduced by Cyril Voyant and co-authors in Sustainable Energy Technologies and Assessments (2025, doi:10.1016/j.seta.2025.104588), score a deterministic solar forecast against persistence-based references, so that a value below 1 means the forecast beats the reference.

Questions about NICEᵏ solar forecast metrics

What do NICE metrics measure in deterministic solar forecasting?

NICEᵏ compares a forecast error norm with the error norm of a specified persistence forecast on the same observations. It is a reference-relative measure of deterministic forecast accuracy. Here, NICEᵏ refers to the solar forecasting framework published by Voyant and coauthors in 2025, with DOI 10.1016/j.seta.2025.104588.

What does a NICE component below one mean in solar forecasting?

For the component defined as the ratio of L-k error norms, a value below one means smaller errors than the chosen persistence baseline. A value of 0.8 means that this error norm is 20% smaller on the evaluated samples. It does not imply a 20% improvement in every error metric or in economic value. A zero baseline norm makes the ratio undefined.

The theory

A raw error says how large the errors are; it does not say whether the model adds anything. NICE answers that by dividing the error of the model by the error of a reference forecast computed on exactly the same samples.

Definitions

\(y_t\)
observation at time \(t\)
\(\hat y_t\)
forecast of the model
\(\hat y^{\,\mathrm{ref}}_t\)
reference forecast, by default persistence \(y_{t-1}\) (the value one step earlier)
\(N\)
number of samples where \(y\), \(\hat y\) and \(\hat y^{\,\mathrm{ref}}\) all exist (missing values are excluded from every term)

Equations

The error of order \(k\) is the \(L^k\) mean error:

$$E_k=\left(\frac1N\sum_{t=1}^{N}\left|y_t-\hat y_t\right|^{k}\right)^{1/k},$$ $$k=1\ (\text{MAE}),\ 2\ (\text{RMSE}),\ 3\ (\text{root mean cubic error}).$$

The NICE component of order \(k\) is the ratio of the model's error to the reference's error:

$$\mathrm{NICE}^{k}=\frac{E_k(\hat y)}{E_k(\hat y^{\,\mathrm{ref}})}=\left(\frac{\sum_t|y_t-\hat y_t|^{k}}{\sum_t|y_t-\hat y^{\,\mathrm{ref}}_t|^{k}}\right)^{1/k},$$ $$\mathrm{NICE}^{\Sigma}=w_1\mathrm{NICE}^{1}+w_2\mathrm{NICE}^{2}+w_3\mathrm{NICE}^{3},$$

with \(w_1=w_2=w_3=1/3\) by default. The two forms of \(\mathrm{NICE}^k\) are equal because both sums run over the same \(N\) samples.

How to read it

  • \(\mathrm{NICE}^{k}\lt 1\): the model's error norm is smaller than the reference's; \(0.8\) means 20 % smaller for that norm on these samples.
  • \(\mathrm{NICE}^{k}=1\): no gain over the reference; above 1, worse.
  • \(k=1\) weighs all errors alike, \(k=2\) penalises large errors more, \(k=3\) more still (ramps, missed clouds).
  • \(1-\mathrm{NICE}^{k}\) is a skill score; always state which one is reported.

Assumptions and validity

Same samples, same horizon and same alignment for the model and the reference; state the reference used. The ratio is undefined when the reference error is zero: report it, do not add a constant. A ratio below 1 does not prove operational value. The repository README adds a note on the constant of Eq. (B.5), checked on the arXiv version of the article.

Run it

Every reference error is twice the model error, so every component is 0.5. Called as nice_metrics(y, y_hat), the reference is persistence y(t-1). Executed with MATLAB R2025b on 22 October 2026.

% from a clone of github.com/cyrilvoyant/nice-metrics
y     = [0; 0];
y_hat = [-1; -2];    % model errors     e = y - y_hat = [1 2]
y_ref = [-2; -4];    % reference errors r = y - y_ref = [2 4]
m = nice_metrics(y, y_hat, y_ref);
fprintf('NICE1 %.2f NICE2 %.2f NICE3 %.2f NICE_Sigma %.2f\n', m.NICE1, m.NICE2, m.NICE3, m.NICE_Sigma);

Output:

NICE1 0.50 NICE2 0.50 NICE3 0.50 NICE_Sigma 0.50

The repository also contains demo_nice.m (teaching demonstration with figures) and the article's own scripts, unchanged, in paper_scripts/.

Reporting protocol

State persistence definition, horizon, temporal alignment, scoring window and missing-value mask. Report absolute errors alongside the ratio. A ratio below one does not establish operational value or superiority to every possible baseline.
